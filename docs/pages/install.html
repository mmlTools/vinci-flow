Install & Setup

Get VinciFlow installed into OBS Studio and your first lower third on stream in about five minutes. No folders or files to configure.

Requirements

  • OBS Studio 32.0 or newer. For older OBS versions use VinciFlow 3.8.x.
  • vinci-flow plugin installed (Windows installer, macOS package, Linux .deb or the Flatpak bundle).
  • obs-websocket is optional unless you plan to automate the plugin externally. (Vendor requests/events require obs-websocket v5 API.)

First-time setup

  1. Open the dock: it appears automatically after installing. If not, use Docks → VinciFlow Controller.
  2. Add the overlay: click Add overlay to current scene. VinciFlow creates a Browser Source sized to your canvas and connects to it. To use it in other scenes, add the same source with Add Existing Source.
  3. Create your first lower third: click New, enter a title and subtitle, pick a Style Preset and click Apply.
  4. Show / hide: click the lower third in the dock. A red LIVE badge shows what is on stream.
  5. Hotkeys (optional): set one in the editor or in Settings → Hotkeys. They are regular OBS hotkeys and work while OBS is in the background.

VinciFlow keeps its files in a resources folder inside the OBS configuration directory. To use another folder (for example a synced one), open Setup in the dock and choose Resources folder.

OBS Flatpak on Linux

Use the dedicated vinci-flow-<version>-flatpak-x86_64.flatpak bundle with the stable OBS Flatpak. Install it with flatpak install --user ./vinci-flow-<version>-flatpak-x86_64.flatpak, using the same installation scope as OBS, then restart OBS.

On first use, VinciFlow creates a writable resources folder under its OBS configuration directory. Existing output folders are preserved. If a selected folder cannot be written, choose another folder using the dock's file chooser. See the Flatpak guide for build instructions, paths, and troubleshooting.

Troubleshooting

"No output dir configured"

Set the Output Directory in the dock/settings first.

Nothing appears on stream

Verify the managed Browser Source is in your current scene and not hidden behind other sources. Confirm it is sized to 1920×1080 and not cropped.

Old design still showing

If you're editing templates or assets, refresh the Browser Source (or disable/enable it) to force reload.

Animations not playing

If you use custom handling, ensure your theme provides root.__slt_show / root.__slt_hide and returns a Promise for hide.
